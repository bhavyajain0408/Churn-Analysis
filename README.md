# Churn-Analysis
Data Analysis  Portfolio Project

An end-to-end **Customer Churn Analysis** project using Python, Pandas, SQL and Data Visualization to identify churn patterns, customer behavior and key business insights.

## 🔍 Project Highlights

* Analyzed customer churn and retention performance
* Identified churn patterns across different subscription plans
* Calculated key business metrics including **Churn Rate, Retention Rate, ARPU and Revenue at Risk**
* Analyzed the relationship between **customer escalations and churn**
* Created **Churn Risk categories** based on customer churn scores
* Performed correlation analysis and visualized important patterns
* Used **SQLite + SQL** for database handling and analysis

## 📈 Key Insights

* **Churn Rate:** 28.57%
* **Retention Rate:** 71.43%
* **ARPU:** ₹18.85
* **Revenue at Risk:** ₹73.94K
* **Average Customer Tenure:** 1,452 days
* **Escalation vs Churn Correlation:** 0.77

### 📌 Churn by Plan

* **Basic:** 60.00%
* **Standard:** 22.22%
* **Premium:** 14.29%

The analysis highlights that **Basic plan customers show significantly higher churn**, while customer escalations have a strong positive relationship with churn.
